| Method           | Checks                                                    | Returns          |
| ---------------- | --------------------------------------------------------- | ---------------- |
| `is_displayed()` | Whether the element is visible                            | `True` / `False` |
| `is_enabled()`   | Whether the element can be interacted with (not disabled) | `True` / `False` |

A hidden element is an HTML element that exists in the page's DOM but is not visible to the user.

Selenium can usually find hidden elements, but it cannot interact with them (click or type)
until they become visible.
